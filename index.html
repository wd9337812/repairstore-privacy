这份政策说明《老街修理铺》当前测试候选如何处理游戏进度，以及你使用平台功能时会发生什么。

当前版本的要点
  • 经营进度、设置和游戏内活跃时长主要保存在本机。
  • TapTap 原生版提供主动读取、明确选档的云备份流程，真实渠道仍待验证。
  • 原生接入候选包含三个自愿奖励广告入口及独立本机聚合检查记录；浏览器试玩不播放商业广告，没有自建统计后台。
  • 宿主 TapDB 事件适配已准备，但本候选远端上报保持关闭，尚未完成真机及后台可见性验证。
  • 开发者对外显示名称为嘀嘀呜的工作室；正式开放前仍需核对实际启用的服务清单。

本政策适用于由嘀嘀呜的工作室维护的《老街修理铺》1.0 发布候选及早期浏览器试玩版本。该工作室名称为开发者确认的对外显示名。本游戏尚未公开正式发行；正式提交时仍将按平台实际要求核对主体字段与服务清单。客服邮箱：wd933781@gmail.com。

这是可供测试者阅读的测试版本政策；它不表示当前广告、平台云同步或发行手续已经通过验证。正式上架资料以届时更新且与实际构建一致的政策为准。

二、游戏处理哪些数据

数据用途与处理方式
经营与维修进度经营日、零钱、订单状态、维修步骤、章节选择、收藏、陈设、收支记录、棋局及本地胜负记录和完成时间等，用于继续游戏和避免重复结算。
界面和声音设置字号、声音开关等，用于记住你的偏好。
游戏内活跃时长保存在进度中的游玩时长和阶段耗时，用于体验验证与进度规则；当前候选没有把它上传到独立分析服务。
平台云备份数据你主动使用原生版云备份时，游戏读取平台提供的用户标识，并用它标记备份归属；明确选择上传时，进度、归属、版本号和备份时间会提交给平台云服务。
广告奖励与频次记录原生接入候选在本机进度内保存广告请求编号、订单、经营日、时间、冷却与奖励凭据，用于限制频次、防止重复结算和恢复异常请求。待处理请求包含平台账号标识，用来避免切号后误结算；这些记录也会随你明确上传的云备份一起保存到平台。
你主动提交的反馈你通过客服邮箱、TapTap 或 GitHub 主动提交的邮件地址、描述、截图、附件等，由相应渠道及开发者处理；仅用于处理你提出的问题。请勿公开提交身份证、手机号、密码、令牌等敏感资料。

当前自编游戏逻辑不主动请求通讯录、精确位置、相机、麦克风权限，不读取这些信息，也不设置真实货币充值或交易市场。TapTap 客户端本身的账号、设备、日志及安全处理另依其服务和政策进行，不能将上述游戏逻辑说明理解为整个平台不处理任何信息。

三、本机保存、导入和云备份

浏览器试玩使用浏览器本地存储。原生测试候选使用平台运行环境提供的文件空间保存进度，并保留上一份有效记录。浏览器版本允许你主动导出或选择 JSON 备份文件导入；该操作不会自动把文件发送给开发者。

原生版的云备份并非自动合并：先读取平台云端，再由你明确选择上传本机快照或恢复云端版本。拒绝或暂不使用云备份，不影响当前候选的本机核心玩法。实际 TapTap 账号、换机、切号、删除及容器保存效果还需在支持环境验证。

请自行保留重要进度。清理浏览器数据、卸载应用或删除运行环境数据可能移除本机进度；删除本机记录不会自动等同于删除平台云备份。

四、平台服务、广告与数据共享

当前候选使用 TapTap Maker / UrhoX 运行环境，原生代码中有平台 clientCloud 云存储适配。平台可能按其政策处理账号、网络和运行日志等信息。更多说明见平台服务说明。

平台广告变现已开通，正在准备验证的原生候选通过 TapTap 宿主提供的接口接入自愿广告：交付后的额外酬谢、旧货收购议价与师傅协助当前一步。只有你主动点击明确标注“看广告”的入口才发起请求；基础工钱、原价收购、免费提示和主线不要求看广告。本机桌面预览及浏览器试玩不展示商业广告，也不模拟真实广告发奖。真实手机播放、账号与异常回调仍待验证，不代表已经公开上线。

广告播放由 TapTap 客户端及其实际启用的广告服务处理，不由自建后端提供。宿主及广告服务可能依据其政策处理账号、设备标识、网络和展示/互动日志；实际组件、提供者、数据种类与所需权限，以手机宿主向你展示的清单和授权为准。当前平台接口未返回完整的下游服务清单，我们尚未逐项独立核实；正式开放前仍需补齐，不能用这份测试政策替代宿主所需授权。自编游戏不安装额外广告 SDK，不接入独立统计 SDK、社交排行榜或 Cloudflare 后端，也不解析广告扩展数据用于画像。

候选代码还具备 TapTap 宿主 TapDB 事件接口适配，但本版本远端上报开关保持关闭，尚未完成手机宿主及后台可见性验证。本机聚合检查不依赖该接口；平台受理不等于广告曝光，宿主统计回调成功也只表示本机持久化，不表示服务器已收到。后续只有在核实真实服务清单、更新本政策并完成必要告知后才启用平台事件上报；届时游戏侧仅提供版本、广告入口类型、玩法阶段和有限结果原因码，不额外传入账号、设备标识、自由文本或完整存档。宿主会自行维护身份和公共属性，因此不能把该能力称作匿名统计。不会为此新增独立统计 SDK 或自建后端。

我们不会主动出售你的游戏进度。你主动选择平台云备份或反馈渠道时，相应数据会由该平台处理；依法必须提供的信息依适用要求处理。

五、保存期限与保护

本机记录保留至你主动清除、覆盖、卸载或运行环境清理。广告入口检查另存有界聚合计数，记录可用入口、可见满一秒、点击、平台受理、最终结果及奖励保存等次数，只用于排查奖励流程，不包含账号、订单标识、逐次轨迹或完整存档，也不随游戏进度云备份上传。检查文件的计数有上限，保留上一份有效副本；重开经营不清除此独立文件。你主动导出后再提交给客服的报告，才会由相应反馈渠道及开发者处理；游戏不自动发送报告。

主动上传的平台云记录用于后续恢复；如需删除，请按下方渠道提出申请，我们会核实归属，并通过平台实际支持的方式处理。平台日志的保存地点、期限和安全措施以平台披露为准，本项目尚未独立核实这些信息，正式启用相应功能前将进一步完善。

游戏采用版本校验、上一份有效备份和明确恢复等方式减少误覆盖，但这些措施不能保证所有设备故障或平台异常下都不丢失数据。反馈排查仅索取处理问题所需的信息。

六、你的选择和权利

你可以在游戏设置中调整字号和声音。原生版可通过“存档设置 → 重新开始一次经营…”主动重开；确认前会说明并先保留独立本机旧档备份，重开不是删除全部备份或平台账号资料。也可使用浏览器版的导出备份；也可以拒绝云备份、关闭游戏、按系统或浏览器指引清除本机数据。需要查阅、更正或删除开发者实际持有的反馈记录，或申请处理平台云记录时，请使用联系与删除页面。我们会先核实请求与数据归属，避免误删他人的记录。

当前没有自建游戏账号，因此没有单独的开发者账号注销功能。TapTap 账号注销、客户端权限和平台记录管理应通过 TapTap 提供的渠道办理。

七、未成年人

未成年人应在监护人指导下阅读本政策。当前候选不提供真实货币购买、玩家聊天或公开个人资料功能。若监护人认为儿童信息被错误提交到反馈渠道，请联系我们核实和处理。正式发行时将依据实际平台要求完善年龄及监护人同意措施，不把本测试政策视为已经完成这些工作。
