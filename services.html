当前平台服务说明

运行环境的服务与游戏自己处理的数据分开列明。当前没有启用的能力，不写成已经接通。

TapTap Maker / UrhoX

用途：游戏运行、平台提供的本地文件空间，以及候选代码中的 clientCloud 手动云备份适配。玩家主动备份时可能处理平台账号标识、游戏进度、归属、备份版本和时间。

平台客户端还可能处理其自身账号、设备、网络和安全日志；具体提供者、数据种类、保存期限、权限和政策应以平台展示的实际版本为准。查看 TapTap 隐私政策。该链接是平台政策入口，不替代正式接入时所需的准确组件清单。

状态：本机核心流程已在开发环境验证；真实账号云备份、切号与换机仍待验证。正式上线前将核对实际客户端版本和服务清单。

广告、统计与自建后端

当前没有启用商业广告，没有集成独立的广告或统计 SDK，也没有部署 Cloudflare 或其他自建游戏后台。未来启用前会更新政策及接入说明，必要时另行征求同意。

GitHub Pages 与 Issues

仅用于托管这组说明页面和接受主动反馈，不接收游戏自动上传的存档。托管服务可能记录 IP 等访问日志；Issues 中提交的内容公开可见。请勿提交账号凭据、身份证、手机号或带有个人资料的原始存档。
